# 浏览器模拟环境

这个目录用于在没有 DevEco Studio 或 HarmonyOS SDK 时，先验证手机端产品流程。

## 打开方式

双击 `index.html` 即可打开。

如果浏览器限制本地脚本，可以双击 `start-simulator.bat`，然后访问：

```text
http://127.0.0.1:8787/
```

## 可验证流程

- 启动页
- 登录和注册
- 青年画像生成
- 首页成长建议
- 7 天、1 个月、3 个月规划
- 五类资源切换
- 收藏、申请、报名、完成、预约
- 智能助手五个动作
- 我的页面
- 离线只读提示
- 桌面成长卡片预览
