# 小艺 Agent 联调验收用例

| 编号 | 场景 | 操作 | 预期 |
|---|---|---|---|
| X01 | 首次绑定 | 小程序生成码，小艺提交码 | 返回绑定成功；同一码再次使用失败 |
| X02 | 绑定码过期 | 超过 10 分钟后提交 | 返回 `BINDING_CODE_EXPIRED`，引导重新生成 |
| X03 | 未绑定画像 | 未绑定身份调用画像 | 返回 `AGENT_USER_NOT_BOUND`，不泄露数据 |
| X04 | 画像更新取消 | 用户未确认更新 | `requiresConfirmation=true`，数据库不变 |
| X05 | 三阶段规划 | 完整画像提交目标 | 返回 7 天、1 个月、3 个月任务 |
| X06 | 政策命中 | 查询沧州就业政策 | 仅返回已发布、未过期结果，每项带来源 |
| X07 | 政策无结果 | 使用不存在关键词 | 明确“暂未找到”，不生成政策 |
| X08 | 资源匹配 | 查询岗位、课程、活动、导师 | 返回评分、原因和真实资源 ID |
| X09 | 报名取消 | 预览后用户说“不报名” | 不进行第二次调用，报名记录不增加 |
| X10 | 报名确认 | 预览后明确确认 | 第二次调用成功，成长记录增加 |
| X11 | 确认篡改 | 更换资源 ID 后复用令牌 | 返回 `CONFIRMATION_MISMATCH` |
| X12 | 确认过期 | 超过确认有效期再执行 | 返回 `CONFIRMATION_EXPIRED` |
| X13 | 今日建议 | 存在逾期和近期任务 | 逾期任务排序第一，同日不重复保存 |
| X14 | 后端异常 | Skill 服务不可用 | Agent 说明暂不可用，不声称已操作 |
| X15 | 英文提问 | 英文询问今日安排 | 英文简答并附中文关键步骤 |

每次联调保存请求时间、operationId、HTTP 状态和脱敏后的结果截图；不得保存真实服务密钥、绑定码或个人敏感信息。
