# 冀青智引 5 分钟演示脚本

## 演示前

- 后端已部署 HTTPS，运行 `seed_demo_data`。
- 小程序登录演示账号 `demo_youth`；密码使用现场环境变量配置值。
- 小艺测试态已导入 `xiaoyi-agent/openapi.yaml`，服务密钥配置完成。
- 清除演示账号的旧绑定、active 计划和当天建议，提前检查网络。

## 0:00–0:35 痛点与定位

画面：小程序首页与成长页。

台词：“河北县域青年面对的不是单一的信息缺口，而是政策分散、路径模糊、资源难匹配、行动难持续。我们基于近 3000 份青年调研和已有服务产品，升级为能持续了解、规划并推动行动的成长 Agent。”

## 0:35–1:10 安全绑定

画面：我的 → 连接小艺 Agent → 生成一次性绑定码；切换到小艺。

对话：“绑定我的冀青智引账号，验证码是……。”

台词：“绑定码十分钟有效、一次使用，后端只保存摘要。小艺不接触小程序密码，未绑定身份不能读取个人数据。”

验收：小艺回复绑定成功。

## 1:10–1:45 画像理解

对话：“你了解我吗？我适合怎么发展？”

小艺调用画像 Skill，展示地区、学历、专业、意向、能力和缺失字段。

台词：“Agent 读取的是用户授权后的真实档案，不是临时猜测。画像发生变化时会先复述变更，确认后才更新。”

## 1:45–2:25 三阶段规划

对话：“我想在河北县域做数字运营，帮我规划未来三个月。”

展示：7 天完成画像与政策了解；1 个月完成课程、活动、岗位行动；3 个月复盘并更新匹配。

台词：“计划不是一段泛化文案，而是带任务 ID、截止时间和真实资源关联的结构化成长计划。”

## 2:25–3:10 政策可信解释

对话：“沧州有什么适合高校毕业生的就业政策？”

展示：政策支持、可能适用理由、仍需确认条件、材料、流程、发布机构和有效期。

台词：“政策由后端先过滤发布状态、地区和有效期。没有结果时明确说没有，避免大模型编造政策。”

## 3:10–4:05 资源匹配与确认行动

对话：“推荐一个适合我的实践活动。”

展示匹配分和原因。继续说：“帮我报名。”小艺先询问确认；用户回答“确认报名”。

台词：“所有写操作都经过两段式确认。短时令牌绑定当前用户、动作和资源，任何篡改或过期都会拒绝。”

验收：小艺返回真实报名成功；小程序成长记录出现该活动。

## 4:05–4:40 主动成长陪伴

对话：“我今天应该先做什么？”

展示逾期或近期计划任务与推荐原因；切回小程序“今日建议”展示同一数据。

台词：“建议来自计划截止时间、画像缺失、历史行为和新资源。小艺与小程序复用同一数据服务，形成持续成长闭环。”

## 4:40–5:00 总结

画面：架构图或后台计划、报名、工具日志。

台词：“冀青智引实现了了解青年、形成画像、制定路径、解释政策、匹配资源、确认行动、记录成长的完整闭环。英语专业成员负责双语内容、政策易懂表达和体验，计算机专业成员负责鸿蒙生态入口、系统和数据安全。”

## 网络异常兜底

- 准备一段不超过 90 秒的完整主链路录屏，仅在现场网络异常时播放。
- 同时展示后端自动化测试结果和 Django 后台真实记录，不将静态录屏描述为实时调用。
- 若小艺服务暂不可用，明确说明测试态网络问题，切换到 API 请求演示同一 Skills 数据。
