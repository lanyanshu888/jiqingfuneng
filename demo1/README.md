# 冀青赋能微信小程序 MVP

河北县域青年成长与就业服务平台演示版，围绕“画像识别 - 资源推荐 - 活动转化 - 数据反馈”的服务闭环开发。

## 已实现页面

- 启动页：项目定位和核心服务入口
- 用户登录：注册、登录并保存登录态
- 首页：搜索、快捷入口、今日推荐、成长进度、服务数据
- 政策一键查：政策分类、青年化政策说明、申请流程详情
- 机会大厅：就业、实习、基层实践、志愿服务、创业项目
- 成长课堂：课程、成长营活动、导师咨询入口
- 我的：成长画像、报名/课程/咨询入口、成长积分
- 青年成长画像：问卷采集并生成用户类型与推荐路径
- 详情页：政策、机会、活动、课程转化动作
- 导师咨询：导师展示、预约、留言提问
- 管理后台演示：数据看板、内容发布、审核管理
- Django 后端：用户注册登录、Token 登录态、青年成长画像保存接口

## 使用方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹：`E:\codex\demo1`。
4. AppID 可使用测试号或继续使用 `touristappid`。
5. 如需测试登录，先启动 Django 后端：

```powershell
cd E:\codex\demo1\backend
python manage.py runserver 127.0.0.1:8000
```

6. 进入后从启动页点击“进入小程序”，即可按答辩演示路径体验。

## 推荐演示路径

用户进入小程序 -> 完善成长画像 -> 查看系统推荐政策、岗位和课程 -> 报名县域青年成长营 -> 进入导师咨询 -> 在“我的”查看成长积分 -> 管理后台查看服务数据。
